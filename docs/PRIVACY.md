# 隐私与信任边界

本原型提供访问控制与认证加密存储；不使用 Zcash 协议、ZK 电路或自建隐私资金池。

| 观察者 | 可见范围 / 限制 |
| --- | --- |
| 本机服务进程 | 能解密全部业务数据；不是端到端加密 |
| 只有数据库副本的人 | AES-256-GCM 密文、总体长度及更新频率；没有金额/地址的明文索引 |
| 同时拿到主机和密钥的人 | 可以解密，不能声称抵御完整主机入侵 |
| 未登录网络请求 | 静态应用壳；私密 API 401；此沙盒登录身份可自选，所以必须仅用假数据并仅监听本机 |
| 付款人 | 所属工作区账单、审批、报价及模拟证据 |
| 管理员 | 固定模拟成员身份；没有付款权限或默认账单读取权限，成员管理未实现 |
| 收款人 | 自己关联的账单，可以核对模拟到账；没有审批权限 |
| 会计 | 指定单据版本的授权字段；撤权/到期立即阻止新读取与导出 |
| 公共链 / 外部服务 | L0 没有链上请求和外部分析；未来 L1 的地址金额公开，L2 出入口/服务方/网络元数据仍有边界 |

每次持久化使用随机 96-bit IV、AES-256-GCM 与固定 schema AAD。数据和附件处于整个认证密文中；损坏标签拒绝解密。该方案没有单独实体密钥、KMS、轮换、细粒度检索索引或生产备份程序。密钥随机生成只用于本地假数据，不含钱包权力。数据目录不纳入 Git。

会话在服务端内存中、有过期时间；HttpOnly 和 SameSite=Strict 防止脚本直接读令牌和跨站携带；写 API 严格校验 Origin。没有真正身份提供方或钱包登录。不能将此身份切换用于真实资金模式。浏览器 sessionStorage 只保存选中的账单 ID，不保存正文、会话令牌或密钥。

所有响应 no-store，私密下载重新鉴权并强制附件下载。文本名称限制字符，UI 输出转义，CSP 禁止外部/内联脚本，无统计分析 SDK。错误不回显输入；审计只记录操作者、对象 ID、类型和时间，不记录业务明文。服务器不记录请求正文。普通启动日志只有 localhost 地址和模拟提示。

授权证据摘要不包含未授权金额/地址。授予查看权不授予支出权，导出也不包含凭证令牌。撤权不能删除会计已经保存的文件或截图。用户在外部钱包自行重复转账也不可能由应用内幂等阻止；本版本没有外部钱包调用。

## PostgreSQL 路径追加

PostgreSQL 使用关系表、逐实体认证密文和工作区/实体 ID AAD；明文关系、成员/角色、版本、状态、revision、结清位和数量可见，金额/地址/正文仍不留明文列。幂等和事件唯一索引使用带域分离的 HMAC tag。审计 AAD 绑定单条 ID，但不宣称防整库回滚、删除或管理员攻击。SQLite 的全状态密文与 PostgreSQL 的泄漏面不同，详见 POSTGRES.md。

认证追加：NEP-413模式不使用自选演示身份；挑战和会话业务载荷认证加密，nonce/token仅存HMAC索引，过期与撤销元数据可见。RPC提供方会看到账户/候选公钥查询，当前只在本地mock中测试。服务器持有解密能力，认证不是端到端隐私。默认仍为L0演示，near模式必须完整配置且不开放真实付款。

L1追加：testUSD 没有美元价值，网络、代币合约、付款/收款账户、金额及随机 UUID memo 在测试链公开。memo 只用于将待签请求与 receipt 绑定，不包含用途或账单摘要，但仍是公共关联标识。准确交易与区块时间核验信任配置的 RPC，不能宣称独立轻客户端验证。配置中的公开账户仅在已认证 L1 settings 返回，公共 config 不暴露成员账户。L1 会计只能通过有效的逐单字段披露接口访问；会计/admin 仍被拒绝读取全部 L1 对象。浏览器 SDK 为构建出的同源代码，不加载远程钱包 manifest 或执行器，不保存账户私钥。

L1版本/披露追加：不可变版本和附件均认证加密，授权接收人仅存HMAC索引，数据库另暴露授权UUID、单据/版本关系、期限与撤权时间。不公开用户账户列表；会计的me/settings不返回资产合约或付款账户。导出与下载重复鉴权，不使用公共缓存；读取期间再次检查撤权/到期。历史授权不随编辑升级，原始receipt不进入狭窄settlement摘要。
