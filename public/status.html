启动与下一步

默认执行 npm ci → npm run build → npm start，得到本地 L0 假数据演示。L1 需要经核实的公开账户、钱包、精确登录域名、testnet RPC/genesis 和 testUSD 合约/精度；详见仓库 docs/L1.md。缺配置时保持关闭。

钱包切换账户或网络不会自动更改服务器登录身份；请退出后按明确的 testnet 登录消息重新认证。签名拒绝或中断不代表付款失败，UNKNOWN 不得重复付款。

禁止项：自动签名或广播、自动退款、L2 保密结算。真实钱包与链上付款尚未验收；不是生产可用声明。
